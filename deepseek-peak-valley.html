计费规则

依据官方定价页（2026-09 调整后）

高峰时段（梁文峰 · 全价）：北京时间 周一至周五（不含中国法定节假日）09:00 – 12:00、14:00 – 18:00。

空闲时段（梁文谷 · 半价）：其余所有时间 —— 包括工作日的 18:00 – 次日 09:00 与午休 12:00 – 14:00、周末全天、法定节假日全天，以及因调休需要上班的周末。空闲时段单价为高峰时段的一半。

页面按北京时间判断，内置 2025–2026 法定节假日表（放假 33 天 / 调休上班 6 天，2026 年），并会在加载时自动从公开日历接口同步最近三年数据；即便离线也能正常判定。节假日以国务院办公厅通知为准。

例：2026 年国庆 10-01 – 10-07 全天空闲，加上前后周末与调休，从 09-30 18:00 起一路到 10-08 09:00 都是「梁文谷价」，连续 7 天 15 小时。

本页的判定逻辑抽在 peak-valley-core.js，与服务端 API 共用同一份代码，因此网页与接口的结果必然一致。接口地址、查询参数与返回示例见下方的开放接口。

参考：官方定价页。调试参数：?preview=valley / ?preview=peak 强制状态，?theme=dark / ?theme=light 强制主题，?t=2026-10-09T10:00:00+08:00 冻结时刻。

开放接口

公有实例 · 无需鉴权 · 已开 CORS

峰谷判定除了画在本页，也以 HTTP 接口对外提供，基址 https://dsfgz.xinwkx.top/v1/fenggu。接口给出当前状态、本段起止与下一次切换时刻；判定逻辑与服务端共用同一份 peak-valley-core.js，所以接口结果和页面显示必然一致。

/v1/fenggu当前峰谷状态 · JSON，默认紧凑，?pretty 缩进
/v1/fenggu.txt同一份数据的纯文本版，适合终端直接 curl
/healthz存活检查 · 运行时长 / 请求数 / 校时源 / 日历年份
?at=查询任意时刻
?format=text纯文本输出
?pretty缩进 JSON
HEAD / OPTIONS探活与跨域预检

?at 接受 ISO 8601（2026-10-09T10:00:00+08:00）或 unix 秒 / 毫秒；不带时区的时间串按北京时间解释。响应头 X-Fenggu: valley|peak 可直接探活，X-Fenggu-CN 给出中文状态，X-Next-At 是下次切换时刻，Server-Timing: app;dur=1.2 是服务端处理耗时。

终端里最快的用法是 curl -s https://dsfgz.xinwkx.top/v1/fenggu.txt；浏览器里直接 fetch('https://dsfgz.xinwkx.top/v1/fenggu') 即可 —— 接口已开放 CORS，无需任何密钥。
